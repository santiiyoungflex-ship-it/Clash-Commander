# AmbiX local vision model training

The training workflow fine-tunes YOLO11n on Roboflow Universe dataset
`bobwatson/clash-royale-cylln-88wu8-yeqpq`, version 1 (145 classes), then
exports a float32 TFLite model for local Android inference.

## One-time GitHub setup

1. In the repository, open **Settings → Secrets and variables → Actions**.
2. Add a repository secret named `ROBOFLOW_API_KEY` containing a Roboflow API key.
3. Open **Actions → AmbiX train local vision model → Run workflow**.
4. Keep the default 80 epochs for the first run.

The workflow trains on the existing train/validation split, evaluates the held-out
test split, exports a 320×320 float32 TFLite model and labels, commits those
assets to `ambiX-from-zero`, and thereby triggers the Android build workflow.

## Important scope and safety

- Dataset license: CC BY 4.0. The model metadata records attribution.
- This model detects arena objects (troops/buildings/spells), not the identities
  of cards in the player's hand and not elixir. Those require a separate HUD/card
  recognition dataset and validation pass.
- Model metrics from the dataset's existing hosted model are not results for
  this newly trained AmbiX model. Use the metrics generated by the workflow.
- The model is a baseline, not a guarantee of 98% accuracy or a competitive rank.
- Automatic gestures remain disabled. Do not enable unattended gameplay until
  the model is evaluated on fresh Moto e32 captures and hand/elixir reading,
  coordinate calibration, and stop controls are verified.
